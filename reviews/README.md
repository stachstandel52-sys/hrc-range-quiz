# Revues poker (bardasphocas, Winamax MTT)

Site statique : une page par semaine revue, plus `index.html` qui les liste.

## Mettre en ligne (GitHub Pages)
1. Créer un dépôt (ex. `poker-reviews`) et y déposer tout le contenu de ce dossier.
2. Settings → Pages → Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.
3. Le site est à `https://<ton-login>.github.io/poker-reviews/`. Sur iPad : Safari → Partager → « Sur l'écran d'accueil ».

Attention : avec un compte GitHub gratuit, un site Pages est public.
